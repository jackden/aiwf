# AIWF v1.7.17.post1 release candidate

- Release and tool version: `1.7.17.post1`
- Workflow protocol: `1.7.10`
- Optional adapter: `aiwf-mcp 0.2.1`

The local stdio adapter uses Query Contract v1 and Mutation Contract v1.
Existing task metadata, event records and dataset formats carry forward.

- Review summaries containing Unicode line or paragraph separators round-trip
  through task-local and global JSONL evidence readers.
- Read operations can discover and inspect legacy tasks when the repository
  enables legacy discovery. The configured records root owns new writes.
- The Runtime uses the server's configured time zone for workday selection.
- Evidence-linked Guidance scope lookup returns note IDs and metadata before the
  adapter applies its output limit. An explicit ID selects an individual note.
- Installation checks for each schema declared by the source Runtime. A
  same-version upgrade from a complete source restores a missing schema.
- Write discovery accounts for permission to maintain the recovery marker.
  Subprocess cleanup preserves the original timeout or output-limit diagnostic.

Use the normal Core upgrade procedure from either a previous release or the
1.7.17 candidate. Update the optional adapter to 0.2.1 in its own environment.
The operator channel requires separate acceptance by a human operator on an
isolated deployment. The source distribution includes deployment instructions in
`integrations/mcp/README.md`. Installed repositories include the [CLI reference](../cli_reference.md).
