# AIWF v1.7.17.post2 release candidate

- Release and tool version: `1.7.17.post2`
- Workflow protocol: `1.7.10`
- Optional adapter: `aiwf-mcp 0.3.1`

The CLI shows how to find a dated task, read its closure status, and tell when
the assigned human reviewer needs to act. The [CLI reference](../cli_reference.md)
and [first-task walkthrough](../examples/basic_lifecycle.md) cover this workflow.
The [upgrade guide](../upgrading.md) also covers recovery using a complete source
package when the target CLI cannot start.

Records packages report the selected task count and the scope of the built-in
privacy checks. Read the [reporting guide](../reporting.md) before handing off
a package. Evidence-linked Guidance and the version 1 query and mutation
contracts continue to use the installed Core.

Adapter 0.3.1 includes action-specific operator help and serves MCP
`2026-07-28` and `2025-11-25` over stdio.
