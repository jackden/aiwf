## Evidence-linked Guidance

Projects can keep reviewed Markdown notes in `.aiwf/guidance/` and link them
to local task evidence. Each note records the conditions for applying its
advice, the cited artifact hashes, and the task-local correction set observed
at review.

```sh
python .aiwf/bin/guidance.py check
python .aiwf/bin/guidance.py show --scope validation
```

`check` validates note structure, artifact references and hashes, and formal
and supported legacy corrections. `show` lists active, scope-matching notes
whose sources can still be verified. Changed or unavailable sources prompt
re-review. Use `show --id <ID>` to inspect a draft, withdrawn, or stale note.
The project reviewer checks the accepted version identified by `review_ref`.

Both `check` and `show` reject explicitly empty or whitespace-only values for
`--scope` and `--id` with exit status `2` before reading any notes. For manual
collection-wide queries, omit both flags. Nonblank selectors retain exact
matching, and repeated `--scope` still uses the last value.

The managed AGENTS template links to the shared Guidance convention for
engineering decisions at task-context start or resume. Use the
[Agent Integration steps](../agent_integration.md#current-usage-pattern) to
refresh the managed block in an existing installation.

## Adoption and Compatibility

The helper uses Python 3.10+ and PyYAML. Install and upgrade preserve the
project's notes, and the public export includes the helper and usage guide.
Queries are read-only and outside workflow completion. Existing tasks can
continue to validate and finalize without Guidance or a records migration.
